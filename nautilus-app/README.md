# Nautilus — companion beta

Standalone application under nautilus-app. React/Vinext, Sites authentication, D1 data storage. No catalogue, billing, email campaign or external data collection.

Install with the Sites dependency helper. Run npm test and npm run typecheck. Use the Sites build workflow for deployment. Schema migrations live in drizzle/. The existing public site is not changed by this folder.

Draft beta: hosted sign-in and account persistence require verification with an authorized user before public release. Do not merge or change production without founder approval.
